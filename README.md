# Канбан учебных задач

Простое Qt-приложение для учёта учебных заданий. Задачи стоят в трёх колонках:

- Планируется
- В работе
- Готово

Просроченные карточки подсвечиваются красным, задачи со сроком в ближайшие 3 дня — жёлтым.

## Сортировки

В меню можно выбрать поле (срок / название / предмет) и алгоритм:

1. **Пузырьком** — соседние элементы сравниваются и меняются местами.
2. **Вставками** — очередная задача вставляется в уже отсортированную часть.
3. **Всплытием** — шейкерная сортировка: максимум «всплывает» в конец, минимум «тонет» в начало.

Код алгоритмов лежит в `src/Sort.cpp`.

## Сборка

Нужны Qt 5 или Qt 6 (модуль Widgets) и компилятор C++.

### Qt Creator

Откройте `KanbanTasks.pro` → Собрать → Запустить.

### CMake

```
mkdir build
cd build
cmake ..
cmake --build .
```

Данные хранятся в текстовом файле `data/tasks.txt` (поля через `;`).
